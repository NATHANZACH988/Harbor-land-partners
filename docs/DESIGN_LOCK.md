# Approved design baseline

The approved site is a premium, welcoming real estate editorial design. **Do not restyle to generic SaaS / AI landing-page motifs** (giant gradients, random blobs, excess rounded cards, neon effects).

- Deep emerald navigation and footer, antique gold CTAs, ivory body background
- Lighthouse logo retained; spacious serif headlines and concise sans-serif body text
- Wide waterfront sunset hero and discreet photo disclosure, not overlaid warning banners
- Four restrained service highlights followed by waterfront/land photographic grid
- About Us and Submit a Deal pairing, region coverage, landowner/buyer paths, full intake form
- Clean responsive navigation, focus indicators, good readability on phone

Reference images in this folder represent the **approved visual direction** rather than fake site listings. Do not use as flattened full-page webpage images.

When changing the homepage, attach before/after desktop and mobile screenshots in the PR. Only switch hero imagery, major type scale, or layout after explicit owner approval.
