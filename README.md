# Harbor Land Partners

Website source repository for Harbor Land Partners.

## Status
**Not deployed.** The approved site package is prepared separately for upload. Live Netlify Forms, notifications, and CRM synchronization must be tested after deployment. Do not treat a thank-you page as proof of successful delivery.

## Website
- Responsive emerald-and-gold editorial branding with lighthouse mark
- Landowner, buyer, markets, about, and submit-a-deal sections
- Illustrative property photographs labeled as such (not available listings)
- No invented deals, metrics, testimonials, or closing guarantees

## Deployment
Target host: **Netlify**, initially using a temporary `netlify.app` address.
- Keep API keys and webhook secrets server-side only.
- Configure Netlify Forms and recipient notifications inside the Netlify dashboard.
- Test a genuine submission from the deployed site before advertising.
- Connect form intake to an **unverified staging table**; never auto-promote inbound leads to approved sellers or offers.
- Require review before outbound contact or binding action.

## Privacy
This repository currently needs its intended **Private** visibility confirmed before the full internal development package is uploaded. The site can be public even when its source repository is private.

## Collaboration
Use pull requests for changes, preserve approved desktop/mobile design references, and run structural and browser tests prior to deployment.
